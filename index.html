Como configurar

Depois de adicionar o bot ao servidor, a configuração leva poucos minutos.

Crie os canais

Separe um canal para o painel de envio e outro para receber as sugestões publicadas.

Execute o comando de configuração

Um proprietário ou membro da staff com permissão de gerenciamento deve usar /painel-sugestoes e escolher os canais.

Pronto

Os membros poderão enviar sugestões pelo painel, votar e debater. A staff controla o status com os comandos administrativos.

🔒 Os comandos administrativos exigem permissões de gerenciamento no servidor. Cada servidor mantém sua própria configuração.

Comandos principais

Os comandos abaixo são usados para configurar e administrar o sistema de sugestões.

⚙️ Configurar painel

Define o canal do painel e o canal onde as sugestões serão publicadas.

/painel-sugestoes

✅ Aprovar

Marca uma sugestão como aprovada pela equipe do servidor.

/aprovar-sugestao

❌ Reprovar

Marca uma sugestão como reprovada e permite registrar uma observação.

/reprovar-sugestao

🟡 Reanalisar

Devolve uma sugestão para o status “Em análise”.

/reanalisar-sugestao

🗳️ Votação

Os membros podem votar diretamente nas sugestões publicadas.

💬 Discussão

Cada sugestão pode receber um tópico próprio para debate da comunidade.
