Política de Privacidade

Esta política explica quais informações o FlameHost Sugestões Bot utiliza para oferecer o sistema de sugestões dentro do Discord.

1. Dados utilizados

Para funcionar, o bot pode armazenar ou processar informações técnicas fornecidas pelo Discord e pelo próprio uso do sistema, incluindo:

  • ID do servidor Discord;
  • IDs dos canais configurados;
  • ID do usuário relacionado a uma sugestão ou voto;
  • conteúdo das sugestões enviadas;
  • registros de votos e status das sugestões.

2. Finalidade

Esses dados são utilizados exclusivamente para publicar sugestões, registrar votos, manter configurações separadas por servidor, permitir discussões e possibilitar o gerenciamento das sugestões pela equipe autorizada.

3. Compartilhamento

O bot não vende dados pessoais. Informações publicadas como sugestões podem ficar visíveis aos membros do servidor Discord conforme as permissões e canais definidos pela própria administração do servidor.

4. Retenção

Os dados necessários ao funcionamento podem permanecer armazenados enquanto forem necessários para manter as sugestões, votos e configurações do servidor. Dados podem ser removidos quando deixarem de ser necessários ou quando o serviço for descontinuado.

5. Segurança

São adotadas medidas razoáveis para proteger os dados utilizados pelo bot. Nenhum sistema conectado à internet, entretanto, pode garantir segurança absoluta.

6. Discord

O FlameHost Sugestões Bot funciona sobre a plataforma Discord. O uso do Discord também está sujeito aos próprios termos e políticas de privacidade da plataforma.

7. Solicitações e contato

Administradores de servidores podem solicitar esclarecimentos sobre os dados utilizados pelo bot por meio dos canais de contato disponibilizados pelo responsável pelo FlameHost Sugestões Bot.

8. Alterações nesta política

Esta política poderá ser atualizada quando o funcionamento do bot mudar. A versão mais recente ficará sempre publicada nesta página.
